# Danny's Unreal Book

A personal piano songbook: choose a song, choose a level, read the music and play.

Open `index.html`, or visit the GitHub Pages site. The sheet music is drawn and played with [abcjs](https://www.abcjs.net/).
`songs.js` is generated from `tools/` with `python3 tools/build.py`.

Every notated melody is public domain. The arrangements are original. Pop requests appear only as chord charts (no melody or lyrics) or as original style studies.
